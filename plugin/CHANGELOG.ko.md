## [1.0.1] — 2026-10-20

### 바뀜
- **현황에도 이지 오토 구간** — 현황 탭 컴팩트 시점 칸(간단 · 자세히)의 컴팩트 구간 바로 아래에 **이지 오토 구간** 드롭다운이 있습니다. 설정 **컴팩트** 탭과 같은 값입니다.

### 고침
- **컴팩트 늦어짐인데 "지금 컴팩트하면 손해"** — Claude Code 가 잠깐 컨텍스트 크기를 비운 때(안전 장치가 응답을 멈춘 뒤, 쉬던 세션 여럿이 한꺼번에)를 훅이 못 본 컴팩트로 셌습니다. 그러면 다음 요청(예: 490k)이 그 컴팩트의 직후 크기가 되어 *상주* 가 490k 로 보이고, 바는 아낄 게 거의 없다며 손해라고 했습니다. 이제 그런 때는 다음 요청이 확실히 작을 때(직전의 8할 아래)만 컴팩트로 셉니다. 0.9.1 ~ 1.0.0 이 이렇게 저장한 기록은 읽을 때 빠지고, **질문별 비용** 의 그 컴팩트 줄도 지워집니다.

## [1.0.0] — 2026-10-19

### 새로 생김
- **이지 오토 컴팩트** — 켜 두면 컨텍스트가 정해 둔 구간을 넘을 때 알아서 저장하고 컴팩트합니다. 답이 끝났을 때 구간 앞쪽을 넘었으면 저장 → 컴팩트, 긴 일 도중 구간 뒤쪽을 넘으면 그 턴을 멈추고 저장 → 컴팩트 → 하던 일을 이어서 합니다. 바의 컴팩트 버튼으로 여는 팝업 오른쪽 위 **이지 오토** 스위치로 세션마다 켜고 끄며(새 세션은 마지막에 고른 값, 터미널은 팝업의 4), 켜져 있으면 바의 컴팩트 버튼 자리에 파란 *오토 200k* 칩 · 바를 접었거나 슬림이면 입력창 아래 *🔄 오토 200k*. 구간은 설정 **컴팩트** 탭 → **이지 오토 구간**(처음 값은 그때의 컴팩트 구간). 사람이 입력해도 꺼지지 않고, 캐시가 만료되거나 모델이 바뀌면 그 세션만 꺼집니다(한 줄 안내). 컴팩트해도 구간 아래로 안 내려가거나 요청 3번 안에 또 넘으면 *오토 멈춤*, 손해인 때(식은 캐시 · 아낄 것이 거의 없음)는 그번만 쉽니다.
- **슬림 화면** — 익숙해진 분을 위한 가장 작은 화면입니다. 평소엔 입력창 아래 버튼 하나(*🟦 120k*)만 있고, 컴팩트할 때 · 늦어졌을 때 · 캐시가 식어 기본 컴팩트가 더 쌀 때만 입력창 위에 알림 한 줄(**[이지 컴팩트]** · ✕). 아래 버튼을 누르면 요약 한 줄. 터미널은 바 자리에 한 줄.
- **화면 프리셋 [슬림 | 간단 | 자세히 | 커스텀]** — 설정 맨 위 한 줄입니다. **커스텀** 은 바 꼴(아래 버튼 · 한 줄 · 세 줄)과 **입력창에 보일 것** 의 칸마다 [끔 | 필요할 때 | 늘]을 고릅니다(*필요할 때* = 그 칸에 색이 든 뒤부터). 정해 둔 프리셋에선 같은 칸이 흐리게 보이고, **처음 값 가져오기** 로 커스텀을 프리셋 값에서 시작합니다. 오늘 · 이번 달 · 한도도 이제 화면 값이라 정해 둔 프리셋에서 바꾸려면 커스텀으로. 쓰던 설정은 보이던 그대로 옮깁니다.
- **진행 중 질문 칸** — 답이 도는 동안 입력창 바로 위에 지금 질문의 금액 · 요청 수가 한 줄로 보입니다(노트북 벌레가 일하고, 에이전트가 돌면 에이전트 그림). 끝나면 사라지고 답변 끝 칩이 잇습니다. 바 셋째 줄은 **지난 질문 줄** — 둘은 따로 켜고 끕니다. 데스크톱 앱의 작업 줄은 앱 그대로 둡니다.
- **에이전트 캐릭터** — 에이전트가 돌면 대장 벌레가 느낌표를 띄우며 손짓하고 작은 벌레들이 깡충 따라 합니다(셋까지, 넘으면 *+N*). 다 끝나면 DONE 현수막과 *에이전트 N개 완료*.
- **값이 오르면 깜빡임** — 컨텍스트 · 세션 금액 · 요청당 · 캐시 만료 글자가 다음 색 단계로 오를 때와 세션에 들어올 때 글자 바탕이 세 번 깜빡입니다(1.8초). 게이지가 움직이는 동안은 쉬고, 설정 **애니메이션**(옛 *움직임*)을 끄면 색만.
- **오늘 · 이번 달 색** — 설정 **숫자 · 색** 에 오늘 · 이번 달 기준 금액(처음 오늘 $50 · $100 · $200, 이번 달 $1,000 · $1,500 · $2,000). 바 · 슬림 · 패널 모든 세션 줄에 색만 들고 깜빡이지 않습니다.
- **[클리어] 를 한 번 더 묻습니다** — 컴팩트 팝업의 **[클리어]** 가 바로 지우지 않고 같은 자리에서 *대화를 지울까요?* — 지울 질문 수와 Claude 가 잊을 크기를 보이고 **[← 돌아가기]**(주 버튼) · **[지우기]**. 터미널은 1 지우기 · 2 돌아가기.
- **컴팩트 문구는 팝업에서 고름** — 팝업에 [일반 | 긴 세션 이어가기 | 마무리 | 직접 쓰기] 툴바가 있고, **직접 쓰기** 면 두 칸에 써서 그 글로 저장합니다. 식은 캐시 팝업도 같은 툴바입니다. 설정 컴팩트 탭의 문구 카드는 한 줄 안내로 바뀌었습니다.
- **질문별 비용 [글 다 보기]** — 잘린 동작 줄이 있는 질문마다 **[글 다 보기 ▾]** 하나. 도구 이름은 종류별 색, 앱 도구는 쉬운 이름(update_plan → *할 일 목록* 등), 에이전트를 띄운 메인 요청은 *에이전트 띄우기*.

### 바뀜
- **게이지 = 사이드 패널 문** — 모든 화면에서 게이지를 누르면 사이드 패널(현황)이 열리고 다시 누르면 닫힙니다. 보통 화면에서 게이지가 열던 요약 카드는 없앴습니다. 슬림 아래 버튼은 현황 패널이 열려 있으면 ▸ — 누르면 패널을 닫습니다.
- **질문 합계는 세션 전체** — 질문 기록은 60개까지만 남지만 밀려난 질문의 개수 · 금액을 따로 모아 합에 넣습니다(1.0 전 기록은 대화 기록에서 어림). 누적엔 있고 질문엔 안 잡힌 요청은 *질문 밖 $X*.
- **갈라 온(포크) 세션은 자기 몫만** — 금액 · 질문 · 컨텍스트 흐름은 갈라 온 뒤 자기 요청만 셉니다. 오늘 · 이번 달은 복사해 온 앞 세션 줄을 두 번 세지 않고, 세션을 다시 켤 때 엔진이 되살린 비용도 두 번 세지 않습니다. 지운 세션 몫은 그달 끝까지 이번 달에 남깁니다.
- **컴팩트 직후 크기 = 컴팩트 뒤 첫 요청** — 엔진이 주는 컴팩트 뒤 크기는 남긴 대화만 세어(시스템 지시 · 도구 · 메모리 빠짐) 직후가 실제보다 작게 적혔습니다(한 세션에서 18k ↔ 실제 106k). 이제 첫 요청 크기로 — 상주 · 계산식 최적 · 컴팩트 효과가 같이 바로잡히고, 옛 기록도 읽을 때 바로잡습니다.
- **숫자 꼴** — 컨텍스트 칸 *645k(64%) / 1M*(눈금 이름도 같은 꼴), 늦어짐 글 *300k(30%) 넘음 · 지금 577k(58%)*, 1센트 미만은 *$0.01 이하*. 자세히 바의 한도 줄은 리셋 시각을 제 한도에 붙여 한 묶음으로.
- **한도 5시간 · 7일** — 칸을 따로 고르고(*5시간 한도* · *7일 한도*), 세션끼리 가장 최근 값을 씁니다(한도를 안 받은 세션도 다른 세션이 받은 값으로).
- **화면 글 말투 · 이름** — 설정 · 현황 · 입력창 둘레 설명을 줄표 · 등호 대신 짧은 문장으로 바꿨습니다. 설정 이름 *움직임* → **애니메이션**, *화면 종류* → **화면 프리셋 설정**, 아래 탭 묶음은 **세부 설정(고른 화면)**.

### 고침
- **일하는 동안 깜빡임** — 요청마다 앱 화면 전체를 다시 그리던 것을 상태를 읽는 칸만 다시 그리도록 줄였습니다(데스크톱).
- **다른 플러그인과 같이** — 입력창 위에 그리는 다른 플러그인의 몫이 우리 바에 가려 안 보였습니다. 이제 바 위에 같이 그립니다.
- **답변 끝 칩 · 질문 이름** — 마무리 도구로 끝난 턴도 칩이 나옵니다(글이 있던 마지막 답 아래). 질문 이름은 숨은 태그를 빼고, 그림만 보낸 질문은 *🖼 그림 N장*.

## [0.9.4] — 2026-10-17

### 바뀜
- **바 줄 맞춤** — 자세히 바의 줄을 다시 묶었습니다: 둘째 줄 = 쌓인 돈(세션 · 오늘 · 이번 달), 셋째 줄 = 지금 값(요청당 · 컨텍스트 · 컴팩트 구간 · 캐시) 뒤에 이번 질문과 컴팩트 버튼. 예전엔 둘째 줄에 6칸이 몰리고 셋째 줄은 질문 하나였습니다. 바가 넓으면 세 줄의 칸이 모두 같은 세로줄에서 시작하고(칸 사이 " · " 없이), 좁으면 예전처럼 칸 사이에서 꺾입니다.
- **바 숫자를 차분하게** — 요금제 한도 % 는 70% 전까지 흐리게(70% 주황 · 90% 빨강) — 금액처럼 튀지 않습니다. *컨텍스트* 는 이름은 흐리게 · 숫자만 색. 금액에 천 단위 쉼표($2,636.86).
- **칸 막대 게이지 = 레벨 미터** — 켜진 칸은 자기 자리 색(1 · 2칸 흰색 · 3칸 주황 · 4칸 빨강), 칸 수는 단계(여유 1 · 2 · 컴팩트할 때 3 · 늦어짐 4). 늦어지면 빨강 칸만 깜빡이고, 컴팩트 중엔 끝 칸부터 차례로 밝아집니다 — 비워지는 쪽(배터리 충전처럼 읽혔습니다). 칸 막대 · 칸 막대 세로 둘 다, 다른 꼴은 그대로.
- **컴팩트 시점 카드** — *지금 하면* · *미룬 비용* 을 이름 칸으로 줄 맞춤(컴팩트 비용은 *비용* 대신 *컴팩트 한 번*). 자세히에선 고른 구간 금액 줄과 *비추천* 줄을 뺐습니다(표의 테두리 줄 · 빨강 줄이 같은 말 — 비추천 구간 풀이는 표의 **?**). *★ 추천 10 ~ 15% · 최적(12%)이 든 구간 [이 구간으로]* 한 줄. 표에서 지금 크기 줄은 파란 ● 와 옅은 바탕.
- **질문별 비용의 이지 컴팩트 표시** — 저장 턴 · 컴팩트 동작 · 칩 상세의 옛 🗜 대신 지금 고른 게이지 꼴을 파랑으로 멈춰 그립니다(지금 컨텍스트를 보이는 게이지가 아님).

### 고침
- **대화창에 진단 줄이 안 나옵니다** — 훅이 못 본 컴팩트가 *easy-compact: compact the hook did not see…* 를 대화창에 찍었습니다. 진단 줄은 디버그 로그에만.
- **입력창 깜빡임** — 바를 닫고 열 때, 입력창 위에 Claude Code 설문(1: Yes …)이 뜨고 닫힐 때 입력창이 깜빡이지 않습니다(데스크톱).
- **바 칸 이름** — *캐시 남은 분* → *캐시 남은 시간*.
- **Anthropic 디렉터리 검사** — 콜백 하나가 이름 `h` 를 써 디렉터리 자동 검사가 따라가지 못해 0.9.2 · 0.9.3 이 디렉터리에 안 올라갔습니다. 이름을 바꾸고 다시 생기지 않게 점검을 더했습니다.

## [0.6.0] — 2026-10-15

### 새로 생김
- **컨텍스트 게이지** — 바의 컴팩트 버튼 앞 아이콘이 게이지입니다(데스크톱). 앱의 컨텍스트 고리와 같은 원 꼴로, 채운 만큼이 지금 컨텍스트, 색은 단계(아직 흐림 · *컴팩트할 때* 주황 · *늦어짐* 빨강)이고 색이 바뀌는 크기는 컴팩트 구간을 따릅니다. 늦어졌고 지금 누를 수 있으면 깜빡이고(빨강 구간이 깊을수록 빠르게, 초당 3번 아래), 컴팩트가 끝나면 줄어드는 모습이 보입니다. 패널 탭 줄 머리 · 확인 카드 제목에도 같은 게이지. 움직임은 설정 → 화면 → **모션** [시스템|줄임]으로 끕니다(운영체제의 동작 줄이기도 따름). 터미널은 아이콘 없이 그대로.
- **컴팩트 문구 두 칸** — 설정 → 컴팩트 문구: **① 컴팩트 전에 보낼 글**([저장하고 컴팩트]의 저장 턴) · **② /compact 뒤에 붙일 글**(요약에 남길 것 — [바로 컴팩트]에도 붙음). 드롭다운(일반 · 긴 세션 이어가기 · 마무리)을 고르면 두 칸이 그 글로 채워지고, 칸을 고쳐 저장하면 *직접 쓰기*. 잃을 정보 확인과 [컴팩트 진행] 표시는 mod 가 앞뒤에 붙입니다. 예전에 *직접* 에 쓴 글은 ① 칸에 그대로 있습니다.
- **새 판 카드** — 이 PC 에 받아 둔 마켓 사본에 새 판이 있으면 현황 탭 맨 위에 *새 판 N 있음* **[바뀐 것 ▸] [업데이트] [닫기]**. 패널을 열 때마다 사본을 다시 읽습니다(통신 없음 — 사본은 Claude Code 가 받아 둡니다). 닫으면 그 판은 다시 알리지 않습니다. 앤트로픽 디렉터리(claude.ai)에서 설치했으면 업데이트 줄은 버튼 없이 *새 판은 Claude Code 를 켤 때 저절로 받습니다*.
- **다시 연 세션의 질문별 비용** — 질문 기록을 세션마다 파일로 남겨(최근 60개) 앱을 다시 켜거나 지난 세션을 열어도 질문별 비용이 보입니다. 기록 파일이 없는 예전 세션은 대화 기록에서 다시 만듭니다(*기록에서 다시 만듦* — 앱 자체 요청 몫은 빠짐).
- **중단한 질문** — 답 도중 멈춘 질문도 줄로 남고 *⏹ 중단됨* 이 붙습니다. 끊긴 요청과 그 사이 앱 자체 요청 값도 그 질문에 들어갑니다(전엔 요청이 0개면 줄째 사라졌습니다).
- **가격표에 없는 모델 알림** — 새 모델이 나와 mod 가격표에 없으면 같은 계열 요율로 세되, 바 세션 금액 옆 ⚠(마우스를 올리면 까닭)와 현황 참고 줄에 *요율 가격이 맞지 않을 수 있음 — 최신 버전에서 반영 예정*. 최대 컨텍스트가 1M 을 넘는 창이면 컴팩트 구간 목록과 직접 정하는 크기의 상한이 창 크기를 따라 늘어납니다.

### 바뀜
- **설정 탭은 앱 설정 화면처럼** — 회색 접는 띠 대신 굵은 칸 제목과 *이름 …… 오른쪽 조작* 한 줄씩, 줄 사이엔 옅은 선. 풀이는 이름 옆 **?** 에 마우스를 올리면 보이고(터미널은 [ ? ] 를 눌러 펼침), 켜고 끄기는 파란 스위치(화면 종류 때문에 못 바꾸는 줄은 흐리게), 하나만 고르기는 묶음 버튼, 값 목록은 드롭다운. 설정 글 양은 화면 종류와 상관없이 같고 미리보기는 늘 보입니다. 업데이트 줄은 맨 위로 옮겼습니다(맨 아래라 찾기 어려웠습니다).
- **컴팩트 시점은 현황 탭에서** — 설정 탭에서 옮겼습니다. 간단 보기는 *이 세션* 카드에 구간 드롭다운과 그 아래 한 줄(판정 · 요청 1회 · 질문 1개 · 캐시 식으면 값), 자세히 보기는 컴팩트 카드에 추천 · 비추천과 색 있는 **크기별 비용** 표(고른 구간은 테두리). 고르는 순간 모든 세션에 적용되고(적용 · 취소 버튼 없음), 드롭다운 끝 **직접 입력…** 으로 크기 하나를 숫자로 정합니다(Enter).
- **비용 표시 순서** — 설정 → 화면의 바 미리보기 아래, 세션 · 오늘 · 이번 달의 여섯 순서. 고르면 미리보기와 바가 바로 바뀝니다.
- **패널 이름 "이지 컴팩트" · 첫 탭 "현황"** — *📊 사용량* 은 담긴 것과 안 맞았습니다. 바의 패널 버튼은 📊 → **◔**. 현황의 [간단|자세히] 는 고른 쪽을 기억하고(설정의 화면 종류를 바꾸면 그 화면의 보기로), 답변 끝 칩을 펼친 꼴로 볼지는 설정의 **답변 칩 자세히**(예전 *정보량* — 커스텀에서 바꿈)가 정합니다. 카드 제목 띠는 없앴고(데스크톱), 접고 펴기는 제목 앞의 작은 칩 **▾ ▸** 입니다.
- **바 컴팩트 버튼** — 쉬는 때 이름은 **컴팩트**, 눌러 확인 카드를 열면 이름 그대로 + **▾**(전엔 ✕ 라 바로 위 창 버튼 ✕ 와 헷갈렸습니다). 상태 그림은 게이지 하나 — 깜빡이는 점은 뺐습니다. 바를 접는 ✕ 는 앱 닫기 버튼 꼴입니다.
- **"컴팩트하기 좋은 때" → "컴팩트할 때", 구간 색 노랑 → 주황** — 바 · 칩 · 패널 · 설정 · 흐름 그래프 기준선 모두. 직접 정한 크기는 *곧 컴팩트할 때* · *컴팩트 권장* 으로 맞췄습니다. 한도 · 캐시 경고의 노랑은 그대로.
- **확인 카드** — 문구는 드롭다운, 고른 문구가 하는 일은 두 줄(*저장* · *답*). 캐시가 식었으면 비용 줄이 빨강, 바로 컴팩트가 더 비싸면 제목이 *지금 컴팩트하면 손해입니다*. 제목 아이콘은 모두 게이지입니다.
- **동작 목록은 최신이 위** — 진행 중 질문도 끝난 질문도 최근 동작이 맨 위, 넘친 것은 맨 아래 *이전 동작 N개* 한 줄(전엔 끝난 질문은 비싼 20개). 답변 끝 칩도 같습니다. 질문별 비용 [전체] 는 20개, 컴팩트 효과 [전체] 는 10개까지 — 패널이 한 번에 그릴 수 있는 크기입니다.
- **글 색은 앱 테마를 따름** — 경고 · 오류 · 성공 글을 앱 테마 색으로 그려 밝은 테마에서도 읽힙니다(전엔 고정색이라 흰 바탕의 노랑 글이 1.4:1). 주황은 한 가지로. 한도 막대는 앱의 사용량 막대 색(파랑, 100% 에서 빨강)입니다.
- **터미널** — 설정 칸 제목 띠는 덜 밝게, 고른 버튼은 ✓, 글 입력칸은 테두리 칸, 켜기/끄기는 [끄기 | 켬](못 바꾸면 둘 다 흐리게). 바가 좁아도 상태 이름(*컴팩트할 때* 등)을 줄이지 않고 비용 줄을 두 줄로 나눕니다 — 터미널엔 게이지가 없어 이름이 곧 상태입니다.

### 고침
- **이번 달 금액이 낮게 나오던 것** — 하위 에이전트 기록에 한 응답이 여러 줄로 적힐 때 첫 줄의 출력만 세었습니다(만든 사람 PC 에선 한 달 출력 약 259만 토큰 ≈ $52 가 빠졌습니다). 이제 그 응답의 가장 큰 값을 셉니다 — 처음 켤 때 이번 달 기록을 다시 셉니다. 날짜 경계는 UTC(한국 시간 오전 9시)이고, 금액의 물결표(~)는 빼고 패널 줄 이름을 *모든 세션(추정)* 으로 했습니다.
- **바는 "늦어짐", 확인 카드는 "손해" 로 엇갈리던 것** — 컴팩트 직후 크기를 컴팩트 뒤 첫 요청(새 질문 · 도구 결과까지 든 크기)으로 재서 직후 크기가 크게 잡혔습니다. 이제 Claude Code 가 알려 주는 컴팩트 결과 크기를 씁니다.
- **node 가 없을 때 같은 오류 줄이 되풀이되던 것** — 재기에 실패하면 10분 동안 다시 재지 않습니다(옵션을 켜면 바로 다시).
- **좁을 때 줄이 "·" 로 시작하던 것** — 바 · 설정 미리보기 · 현황에서 넘친 줄을 칸 사이에서 나누고, 줄 머리에 점을 붙이지 않습니다. *본전* · *★ 최적* 처럼 한 낱말만 다음 줄로 떨어지던 것도 칸째 내려갑니다.

- **답변 끝 질문 비용 `이 질문 $X · 요청 N회` 이 잘 보이게** — 흐린 회색이라 답변 글 사이에서 안 보였습니다. 데스크톱은 둥근 파란 테두리 칩(🧾), 글은 전부 파랑 · 금액만 굵게. 터미널은 테두리 없이 같은 파랑 한 줄(테두리는 답마다 두 줄을 늘림). 금액에 따른 색은 넣지 않습니다 — 큰 작업이 나쁜 게 아닙니다. *캐시 다시 씀* 경고만 노랑. 답변 글에 붙어 보이지 않게 한 칸 띄우고, 정보량 **전부** 면 칩 끝 **▸ 자세히** 로 그 질문만 펼쳐 사용량 패널 자세히의 펼친 질문처럼 메인 · 🤖 에이전트 · 앱 자체 요청 분해 줄과 동작별 값을 봅니다(처음엔 접힘. 맨 위 ` - ` 줄 — 메인 · 🤖 · 🗜 · ⚙ — 의 합이 질문 값이고, 동작 줄은 메인 아래로 더 들여 메인 금액을 나눈 것 · 비싼 동작 10개, 나머지는 한 줄). 첫 줄엔 합과 요청 수만 — 앱 자체 요청 · 컴팩트는 펼친 줄에(터미널은 첫 줄에 "… 포함"). 터미널은 칩 한 줄만.
- **질문 강조** — 답변 끝 질문 비용 칩이나 사용량 패널의 그 질문 줄에 마우스를 올리면 칩 · 패널 줄 · 채팅창의 그 답변이 함께 회색이 됩니다 — 어느 답변의 값인지 보입니다. 답변 글에 올려선 반응하지 않고, 채팅은 스크롤되지 않습니다. 설정 미리보기의 견본 칩도 같이 반응합니다. 데스크톱만, 설정 → 화면 → 세부 → 모든 화면 공통의 **질문 강조**(기본 켬).
- **설정 정리** — 세부는 **정보량** 이 맨 앞(패널 · 설정 · 답변 끝 칩까지 넓게 바꾸는 큰 스위치), 그다음 바 칸, 모든 화면 공통. 터미널 설정 탭에선 쓰지 않는 옵션(질문 강조 · 패널 같이 여닫기)을 뺍니다. 사용량 패널의 질문 제목은 그냥 글 — 열기 · 닫기는 왼쪽 ▸ 버튼.
- **비용표 `질문 1개(10회 가정)`** — 질문 하나 = 요청 10회로 고정합니다. 이 세션 평균으로 세면 큰 작업일수록 값이 커져 기준점이 안 됐습니다. 풀이 줄에 *요청 10회 가정* · 이 세션 평균 요청 수 · 그 수로 센 100k ~ 1M 값을 색으로.
- 패널 위 **간략 · 자세히** 는 잠깐 보기 — 패널을 닫거나 설정 탭에 다녀오면 정보량대로 돌아갑니다.
- 설정 칸 펼침: 처음엔 화면과 그 세부만 펼침. 패널을 연 채 사용량 ↔ 설정을 오가면 그대로, 패널을 닫았다 열면 처음대로.
- 언어 칸: 모르면 *자동*, 알면 *자동(한국어)*.
- 좁은 터미널(패널을 연 CLI)에선 패널 버튼을 `사용량 ✕` 로 줄였습니다 — 한 줄 바의 왼쪽 글이 잘렸습니다.

### 고침
- **캐시 유지 시간을 짐작하지 않고 세션에서 잽니다.** Claude Code 가 요청마다 정하고(구독 요금제 사용량 안 1시간, API 키 · 클라우드 · 사용량 초과 5분, 또는 `promptCacheTtl` 값) 기록에 남깁니다. 남은 시간은 `42/60분`, 경고는 유지 시간마다 따로(1시간 10분 · 5분 2분), 식은 캐시를 다시 쓰는 값도 그 유지 시간의 쓰기 요율. 예전엔 늘 1시간 쓰기로 세 5분 세션은 1.6배 높았습니다. 첫 요청을 재기 전엔 *추정* 이라고 적습니다. 커스텀에서 사용자 설정의 `promptCacheTtl` 을 바꿀 수 있습니다.

- **식은 캐시 셈에 공통 앞부분**: 다른 세션이 데워 둔 시스템 · 도구는 읽기로 셉니다(예: Sonnet 5.5 15만 · 1시간 캐시, 이어 가기 $0.60 → $0.42).

- **컴팩트 요약 크기**를 컴팩트 뒤 첫 요청이 새로 쓴 양으로 잽니다 — *요약 1k 포함* 처럼 작게 나오던 것.
- 모델을 바꾸면 설정 · 카드 값이 다음 요청을 기다리지 않고 바로 새 모델 요율로.

- **바를 끄면 다시 켜는 법을 알려 줍니다** — 입력창 아래 버튼을 누르거나 `/easy-compact 보이기`. 끄기는 잠시 쉬는 용도이고, 지우기는 따로입니다.
- **단축 명령:** `/easy-compact 보이기` · `안보이기` · `자동숨김 켜기|끄기` · `최소` · `최대` · `패널`. 영어도 됩니다.
- **사용량 패널 옵션**(설정 → *사용량 패널*, 또는 `패널 자동` / `패널 같이`): 새 세션에서 자동으로 열기(기본 끔), 데스크톱 세션끼리 같이 열고 닫기(기본 켬).
- 한 줄 바에도 이지 컴팩트 버튼과 *컴팩트할까요?* 카드가 있습니다.
- 설정 칸은 처음엔 접혀 있고, 제목 줄에 지금 값이 보입니다.

### 바뀜
- 띠의 이름이 **이지 컴팩트 바**로 바뀌었습니다. 0.2.0 의 보기 셋은 크기(전체 · 한 줄) · 자동 숨김 · 끄기로 나뉘었습니다.
- 바의 상태는 깜빡이는 점과 강조 버튼으로 보입니다. 🗜 아이콘은 컴팩트할 만할 때 · 컴팩트 중엔 파랑, 그 밖엔 회색입니다.
- **컴팩트를 권하지 않을 때** — 컴팩트 구간 전, 방금 컴팩트함, 캐시가 만료됐어도 컴팩트가 더 비쌀 때 — 🗜 가 회색이 되고 까닭은 마우스를 올리면 보입니다. 버튼을 누르면 카드에 자세한 숫자가 그대로 나옵니다. 답하는 중(누를 수 없을 때)에도 회색입니다.

### 고침
- **캐시 만료를 마지막 요청 시각으로 잽니다.** 세션을 다시 열거나 이름을 바꾸면 만료된 캐시가 살아 있는 것처럼 보이던 문제 — 이제 *캐시 만료 · 바로 컴팩트 권장* 이 제때 뜹니다.
- 컴팩트 직후엔 *컨텍스트 0* 대신 추정 크기를, 캐시 남은 분 대신 *캐시 없음(다음 요청이 새로 씀)* 을 보입니다. 컴팩트 전의 지난 질문 줄은 다음 요청까지 숨깁니다.
- *컴팩트할까요?* 카드의 식은 캐시 줄이 바와 같은 셈을 씁니다. 예전엔 다시 쓰기 몫만 초록으로 보여, 바의 *손해* 옆에서 이득처럼 읽혔습니다.
- 기록이 4MB 넘는 세션을 다시 읽습니다 — 0.2.0 꾸러미에 도움 스크립트가 빠져 있었습니다.
- 누른 뒤 남던 마우스 설명을 고쳤습니다. 모르는 명령엔 한 줄로 답합니다.
