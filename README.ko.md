## 필요한 것

| | |
|---|---|
| **Claude Code** | **2.1.295 이상.** 데스크톱 앱: Code 탭 세션에서 `/status` → **Claude Code** 줄(앱 정보의 앱 판 번호가 아님). 터미널: `claude --version`. 낮은 판에선 바가 아예 안 뜰 수 있고, easy-compact 가 시작될 수 있으면 바 자리에 업데이트 안내 한 줄이 뜹니다. |
| **업데이트** | 데스크톱 앱: **Claude → Check for Updates**(macOS) · **Help → Check for Updates**(Windows) 뒤 새 세션. 터미널: `claude update`. Homebrew 의 `claude-code` 는 늦은 stable 채널이라 아직 낮습니다 — `brew install --cask claude-code@latest`. |
| **git** | GitHub 에서 마켓을 추가할 때 필요 — `git --version` 이 판을 찍으면 됩니다. macOS: 개발자 도구 설치 창이 뜨면 설치하세요. Windows: [Git for Windows](https://git-scm.com/downloads/win). |
| **보이는 곳** | Claude 데스크톱 앱(Code 탭)과 터미널의 `claude`. VS Code 확장 채팅 · `claude -p` · 클라우드 세션 · WSL 세션에선 안 보입니다. |
| **선택** | Node.js 14.8 이상 — 설치 전부터 이어 온 아주 긴 세션(기록 4MB 넘음)의 앞 구간까지 그리고, 오늘 · 이번 달 사용량(패널 모든 세션 줄 · 바 옵션)을 셉니다. |
| **시험한 곳** | Windows 11, 데스크톱 앱 · 터미널. OS 에 묶인 코드는 없지만 macOS · Linux 는 아직 실물로 시험하지 않았습니다 — 써 보고 알려 주세요. |

## 설치

**처음 한 번만.** 데스크톱 앱과 터미널은 같은 설정을 써서, 한 곳에서 설치하면 둘 다 됩니다.

**가장 쉬운 길 — Claude 에게 이 한 줄을 보내세요**(데스크톱 앱 Code 탭이든 터미널 세션이든):

```
이 플러그인 설치해줘: github.com/JaeSeongHa5280/easy-compact (claude plugin marketplace add JaeSeongHa5280/easy-compact 후 claude plugin install easy-compact@easy-compact)
```

그다음 Claude 앱을 완전히 껐다 켜거나 새 `claude` 세션을 엽니다. 입력창 위에 이지 컴팩트 바가 뜹니다.

<details>
<summary><b>직접 치려면</b></summary>

**Claude 입력창에서 — 한 줄씩 따로 보내세요.** 첫 줄이 끝난 뒤 둘째 줄을 보냅니다. 두 줄을 한 번에 붙여 보내면 설치가 안 됩니다.

```
/plugin marketplace add JaeSeongHa5280/easy-compact
```

```
/plugin install easy-compact@easy-compact
```

- **데스크톱 앱:** 첫 줄을 치면 **마켓플레이스 추가** 창이 뜹니다 — **동기화** 를 누르세요. 빨간 경고는 Anthropic 이 운영하지 않는 마켓이면 늘 뜨는 안내입니다. 둘째 줄을 치면 플러그인 목록에 easy-compact 가 보입니다 — 설치하세요.
- **터미널 세션:** 둘째 줄을 치면 플러그인 정보가 열립니다 — **Install for you** 를 고르세요.

**터미널(macOS 터미널 · Windows PowerShell)에서:**

```
claude plugin marketplace add JaeSeongHa5280/easy-compact
claude plugin install easy-compact@easy-compact
```

`claude` 명령이 없으면(데스크톱 앱만 쓰면 보통) 위의 한 줄을 Claude 에게 보내세요.

</details>

> **Claude 에게:** 먼저 엔진 판이 2.1.295 이상인지 보세요(`<엔진> --version`). 낮으면 설치하지 말고 위 [필요한 것](#필요한-것)의 업데이트 길을 안내하세요. `claude` 가 PATH 에 없으면(데스크톱 앱이면 보통) 지금 도는 엔진으로 돌리세요 — 엔진 경로는 `CLAUDE_CODE_EXECPATH`, 없으면 `CLAUDE_PID` 의 실행 파일입니다. macOS · Linux: `"$CLAUDE_CODE_EXECPATH" plugin marketplace add JaeSeongHa5280/easy-compact` 다음 `"$CLAUDE_CODE_EXECPATH" plugin install easy-compact@easy-compact`. Windows PowerShell: `& $env:CLAUDE_CODE_EXECPATH plugin marketplace add JaeSeongHa5280/easy-compact` 다음 `& $env:CLAUDE_CODE_EXECPATH plugin install easy-compact@easy-compact`(변수가 없으면 `(Get-Process -Id $env:CLAUDE_PID).Path`). `git` 이 없어 마켓 추가가 실패하면 git 설치를 안내하세요(macOS 는 `xcode-select --install`). 이미 설치된 것을 업데이트할 땐 같은 엔진 경로로 `plugin marketplace update easy-compact` 를 먼저, 그다음 `plugin update easy-compact@easy-compact` — 첫 단계 없이는 옛 판을 최신이라고 답합니다. `plugin list` 에서 `easy-compact@easy-compact` 가 enabled 인지 보고, 앱을 완전히 껐다 켜 달라고 안내하세요. 이 저장소를 clone 하거나 `settings.json` 을 고치지 마세요.

## 업데이트 받기

**0.5.0 부터는 앱 안에서:** 바의 **게이지** — **컴팩트** 앞 칸 막대(0.9.0 은 가로 막대, 0.8.x 는 동그라미, 0.6~0.7 은 **◔**, 0.5.x 는 **📊**) → 패널 오른쪽 위 버전 버튼(`v0.9.1`, 0.6.x 는 **⚙ 설정** 탭 맨 위 업데이트 줄, 0.5.x 는 설정 맨 아래 **easy-compact** 칸) → **[업데이트 확인]** → 새 버전이면 **[업데이트]** → Claude 를 다시 켜기. 누를 때만 Claude Code 가 GitHub 에서 마켓을 받아 옵니다. 새 버전이 이미 받아져 있으면 버튼이 *N 업데이트*(0.9.0 까지는 *새 판 N*)가 됩니다(0.6.x 는 **현황** 탭 맨 위 *새 판 N 있음* 카드와 설정 탭 이름의 점(•)).

**0.4.1 이하이거나 직접 하려면 Claude 에게 이 한 줄을 보내고**, Claude 를 다시 켜세요.

```
이 플러그인 업데이트해줘: easy-compact (claude plugin marketplace update easy-compact 후 claude plugin update easy-compact@easy-compact)
```

셸에서 직접 하려면 이 두 줄입니다:

```
claude plugin marketplace update easy-compact
claude plugin update easy-compact@easy-compact
```

- 설치 줄을 다시 치면 "이미 설치됨"만 나오고, `plugin update` 만 치면 옛 판을 최신이라고 답합니다 — 첫 줄이 새 목록을 받아 옵니다.
- 쓰던 설정(컴팩트 구간 · 고른 화면 등)은 그대로 남습니다. 0.4.0 의 **기본** 화면은 없어져 **간단** 으로 바뀝니다.
- **새 판을 저절로 받으려면:** 터미널 세션에서 `/plugin` → **Marketplaces** → **easy-compact** → **Enable auto-update**. Anthropic 이 운영하지 않는 마켓은 꺼진 채로 시작합니다([Claude Code 문서](https://code.claude.com/docs/en/plugins/install)).
- 내 판 번호: `claude plugin list`. 무엇이 바뀌었나: [변경 기록](CHANGELOG.ko.md) · [릴리스](https://github.com/JaeSeongHa5280/easy-compact/releases).

## 0.9.2 에서 바뀐 것

- **금액이 앱 설정(사용량) 화면과 맞음** — Sonnet 5.5 캐시 읽기 인하($0.20 → $0.10)를 설정 화면이 실제로 반영한 10월 15일부터 셉니다(가격표 발표는 10월 7일). 대조한 PC 에서 이번 달 약 $919 vs 설정 $920 — 전엔 $140 넘게 낮았습니다. 패널 맨 아래 요율 줄에도 적힙니다.
- **게이지 모양 "칸 막대 세로"** · **칸 막대 둘 다 배터리 테두리** — 네 칸이 아래부터(설정 **바** 탭 → **게이지 모양**), 기본은 칸 막대(가로) 그대로.
- **지난 기록은 그날 요율로** — 기록에서 다시 만든 질문별 비용 · 컨텍스트 흐름 · 컴팩트 효과 · 다른 모델 값이 요청 날짜의 요율로 셉니다.
- **업데이트 확인이 "확인 중…" 에 멈추지 않음** — 여러 번 눌러도 명령은 하나, 응답이 없으면 90초 뒤 멈추고 **[다시 시도]**, 남은 표시는 버전 버튼을 다시 누르면 풀림.
- **크기별 비용 표 풀이** — *파란 바탕 = 지금 컨텍스트 · 테두리 = 고른 컴팩트 구간*.
- **질문 강조는 처음엔 꺼짐** — 켜려면 설정 **답변 칩** 탭 → **질문 강조**(설정을 저장한 적이 있으면 쓰던 값 그대로).

<summary><b>0.9.0 에서 바뀐 것</b></summary>

- **게이지는 가로 막대가 기본** — 고리는 입력창 오른쪽 앱 컨텍스트 고리와 똑같아 헷갈렸습니다. 설정 **바** 탭 **게이지 모양** 에서 **가로 막대** · **고리** · **세로 막대** · **칸 막대** 를 고릅니다(바 · 패널 머리 · 컴팩트 카드가 같이).
- **컴팩트 카드: 이지 컴팩트 · 클리어 · 취소** — *저장하고 컴팩트* 는 **이지 컴팩트**, *바로 컴팩트* 자리엔 **클리어**(/clear). 캐시가 식은 카드는 저장 질문 없이 **기본 컴팩트**(Claude 의 /compact — 뒤에 붙는 글을 보여 줌) · **클리어** · **취소**.
- **설정은 탭** — 맨 위 화면 종류 아래 **바 · 답변 칩 · 패널 · 컴팩트 · 일반**. 바 탭은 **바 전체 · 한도 줄 · 비용 줄 · 질문 줄** 카드마다 그 줄만 미리보기.
- **접힌 바 버튼 = 색 네모 하나** — 입력창 아래 **🟦 이지 컴팩트**, 네모 색이 크기 단계(🟦 여유 · 🟧 컴팩트할 때 · 🟥 늦어짐). 터미널은 접힌 동안 바 자리에 **[⇱ 이지 컴팩트]**(ctrl+x tab → Enter).
- **입력창 아래 한 줄**(옵션) — 턴 끝 "다음 단계" 상자가 떠 있는 동안 앱이 바를 잠시 빼도, 바의 요지가 입력창 아래에 남습니다.
- **현황** — 컴팩트하는 동안 막대가 숨 쉬고 끝나면 줄어듦, 컴팩트 시점 막대는 왼쪽부터, 크기별 비용 표에 지금 컨텍스트 줄, **컨텍스트 숫자**(크기 · % · 둘 다)를 컴팩트 카드도 따름.
- **진단 · 제보** — 패널 판 버튼 서랍의 **[진단]** 이 이 세션 상태를 파일 하나로 남깁니다(0.9.1 부터 [진단 내용 보기]). `/easy-compact` 명령은 뺐습니다(바의 ✕ · 접힌 바 버튼이 같은 일).

</details>

바에는 세션 금액($10 · $50 · $100 을 넘으면 노랑 · 주황 · 빨강 — 설정에서 바꿈), 5시간 · 7일 요금제 사용량, 캐시 남은 시간(`캐시 만료까지 42분 남음`), 컨텍스트 게이지(누르면 이지 컴팩트 패널)와 **컴팩트** 버튼, 창 버튼(오른쪽 위)도 있습니다. 처음엔 **간단** 화면이라 한 줄(세션 금액 · 컨텍스트 · 캐시 · 컴팩트)입니다. 설정에서 켜면 오늘 · 이번 달 금액(이 PC 의 모든 세션)도 붙습니다 — 패널 **현황** 탭을 자세히로 보면 맨 위에 늘 있습니다. 다 보려면 설정 맨 위 **화면 종류** 에서 **자세히**, 칸을 하나씩 고르려면 **커스텀** 을 고르고 **바** 탭의 줄 카드(한도 줄 · 비용 줄 · 질문 줄)에서 칸을 켜고 끕니다 — 카드마다 그 줄 미리보기가 따라 바뀝니다. 돈 칸(세션 · 오늘 · 이번 달) 순서는 **비용 표시 순서**, 컨텍스트를 크기 · % · 둘 다로 볼지는 **컨텍스트 숫자** — 둘 다 **비용 줄** 카드에 있습니다. 게이지 꼴은 **바 전체** 카드의 **게이지 모양**(칸 막대(기본) · 가로 막대 · 고리 · 세로 막대 · 칸 막대 세로 — 아래 네 단계 견본). 견본은 옅은 바탕에 파란 **미리보기** 칩이 붙은 것입니다(버튼은 눌러지지 않음). 거슬리면 한 줄로 줄이거나 컴팩트할 때까지 접어 두세요 — [숨기기 · 접기 · 다시 켜기](#숨기기--접기--다시-켜기). 에이전트를 띄우면 그 몫이 `🤖 에이전트 1개 $X 포함` 으로 붙습니다.

<img src="docs/img/screen.png" width="520" alt="설정: 화면 종류(간단 · 자세히 · 커스텀) 아래 탭 바 · 답변 칩 · 패널 · 컴팩트 · 일반, 바 탭은 줄 카드마다 미리보기">

**설정: 맨 위 화면 종류(간단 · 자세히 · 커스텀), 그 아래 탭 — 바 · 답변 칩 · 패널 · 컴팩트 · 일반.** 바 탭은 **바 전체 · 한도 줄 · 비용 줄 · 질문 줄** 카드마다 그 줄을 이 세션 값으로 미리 그리고, 바로 아래 그 줄을 바꾸는 칸이 있습니다(지금 화면에 없는 줄은 까닭을 한 줄로). 화면 종류가 바의 칸, 현황 탭의 처음 보기, 답변 칩을 펼친 꼴로 볼지(**답변 칩 자세히**)를 정하고, 커스텀이면 하나씩 고릅니다 — 화면 종류가 정하는 칸은 흐리게 보입니다.

### 2. 질문별 비용, 동작마다

<img src="docs/img/live.png" width="760" alt="진행 중 질문: 동작마다 한 줄과 금액">

**Claude 가 일하는 동안, 동작마다 한 줄과 금액이 붙습니다.**

<img src="docs/img/history.png" width="760" alt="끝난 질문을 펼친 모습: 읽기 · 쓰기 · 출력, 그리고 동작별 값">

**끝난 질문은 펼쳐 봅니다**(자세히 보기): 메인(읽기 · 쓰기 · 출력) · 🤖 에이전트 · 🗜 컴팩트 · ⚙ 앱 자체 요청, 그리고 동작별 값(최신이 위, 넘친 것은 맨 아래 *이전 동작 N개*). `(+42k)` 는 그 질문이 늘린 컨텍스트입니다. 간단 보기에선 펼치지 않고 질문마다 `요청 N회 · 🤖 에이전트 N개` 와 총액만 보입니다. 앱을 다시 켜거나 지난 세션을 열어도 질문별 비용이 남고, 도중에 멈춘 질문은 *⏹ 중단됨* 으로 남습니다.

<img src="docs/img/question-cost.png" width="900" alt="답변 아래 파란 질문 비용 칩을 펼친 모습(메인 요청 · 에이전트 · 동작), 마우스를 올려 그 답변과 이지 컴팩트 패널 줄이 함께 강조됨">

**답변마다 끝에 파란 칩 — 그 질문에 든 값.** 자세히 화면에선 **▸ 자세히** 로 그 자리에서 펼칩니다 — 메인 · 🤖 에이전트 · 🗜 컴팩트 · ⚙ 앱 자체 요청과 비싼 메인 동작. 칩이나 패널의 그 질문 줄에 **마우스를 올리면** 답변 · 칩 · 패널 줄이 함께 회색이 됩니다(데스크톱, 설정 **답변 칩** 탭 → **질문 강조** 를 켜면 — 처음엔 꺼짐).

### 3. 언제 컴팩트할지

<img src="docs/img/settings.png" width="640" alt="현황 → 컴팩트: 컴팩트 구간 드롭다운과 크기별 비용 표 — 판정 색, 고른 구간은 테두리">

**현황 탭에서 컴팩트 구간을 고릅니다.** 간단 보기는 *이 세션* 카드의 구간 드롭다운 — 그 아래 한 줄에 판정(★ 최적 · 좋음 · 보통 · 비추천)과 요청 1회 · 질문 1개 · 캐시 식으면 값. 자세히 보기는 컴팩트 카드에 ★ 추천 · 비추천과 **크기별 비용** 표 — 크기마다 읽기 1회 값과 질문 1개 값(요청 10회 가정 × 지금 모델 요율), 패널이 넓으면 캐시가 식었을 때 값과 가장 싼 크기(★)보다 얼마나 더 드는지도(좁으면 덜 중요한 열부터 뺍니다). 칸 색이 판정이고 고른 구간은 테두리입니다. 고르는 순간 모든 세션에 적용되고, 드롭다운 끝 **직접 입력…** 으로 크기 하나를 숫자로 정합니다.

| 게이지와 버튼 | 뜻 |
|---|---|
| 흐린 게이지 · 보통 **컴팩트** | 아직 아님 — 구간 전, 방금 컴팩트함, 컴팩트가 더 비쌈. 마우스를 올리면 까닭 |
| 🟠 주황 게이지 · *컴팩트할 때* | 구간 안 |
| 🔴 빨강 게이지(깜빡임) · *컴팩트 늦어짐* | 구간을 넘음 — 깊을수록 빨리 깜빡입니다 |
| 🔴 *캐시 만료* · **기본 컴팩트 권장** | 캐시가 식었고, 지금 컴팩트하는 쪽이 전체를 다시 보내는 것보다 쌈 |

게이지에 마우스를 올리면 지금 컨텍스트와 고른 컴팩트 구간(크기 · % · 둘 다 — **컨텍스트 숫자**)이 보이고, 누르면 이지 컴팩트 패널이 열립니다. 버튼에 올리면 지금 상태와 할 일이 보입니다. 게이지는 처음엔 칸 막대 — 설정 **바** 탭 **게이지 모양** 에서 가로 막대 · 고리(앱 컨텍스트 고리 꼴) · 세로 막대 · 칸 막대 세로로 바꿉니다. 칸 막대 · 칸 막대 세로는 배터리 테두리 안에 칸이 있습니다. 색 · 깜빡임 · 컴팩트 끝 줄어듦은 꼴과 상관없이 같고, 컴팩트 · 저장하는 동안엔 진행 파랑으로 꼴마다 움직입니다(막대 숨쉬기 · 고리 도는 호 · 칸 막대 차례로).

### 4. 이지 컴팩트 — 클릭 한 번

<img src="docs/img/confirm.png" width="860" alt="컴팩트할까요 카드: 312k 에서 82k, 질문당 아끼는 값, 이지 컴팩트 · 클리어 · 취소">

<img src="docs/img/keep-working.png" width="860" alt="캐시가 식었고 지금 컴팩트하면 더 비쌈: 카드에 작업을 이어 가세요와 확인 버튼만">

**"컴팩트할까요?" 카드에 질문당 아끼는 값과 컴팩트 비용이 보입니다.** 카드의 문구 드롭다운(일반 · 긴 세션 이어가기 · 마무리)으로 무엇을 남길지 고르면, 고른 문구가 하는 일이 두 줄(*저장* · *답*)로 보입니다 — 두 글은 설정 **컴팩트** 탭 → **컴팩트 문구** 에서 직접 쓸 수도 있습니다(**① 컴팩트 전에 보낼 글** · **② /compact 뒤에 붙일 글**). 버튼은 **▶ 이지 컴팩트** · **클리어**(/clear — 요약 없이 대화를 비우고 새로 시작) · **✕ 취소**. 캐시가 식었으면 *캐시 만료* 카드 — 그냥 이어 가기와 기본 컴팩트의 값, 저장 질문 없이 **▶ 기본 컴팩트**(Claude 의 /compact, 뒤에 붙는 글을 그대로 보여 줌) · **클리어** · **✕ 취소**(저장 질문이 먼저 전체를 다시 쓰기 때문). **지금 컴팩트하면 손해인 때**(식은 캐시인데 그냥 이어 가는 편이 싸거나, 아낄 게 거의 없을 때)엔 컴팩트 버튼 없이 *작업을 이어 가세요* 만 보입니다 — 돈 판단은 easy-compact 가 숫자로 하고, 세션에 맡기지 않습니다. 터미널에선 카드 버튼에 번호가 붙습니다 — **1** 이지(기본) 컴팩트 · **2** 클리어 · **3** 취소, 빈 입력창에서 그 숫자만 쳐도 눌립니다. **이지 컴팩트** 를 누르면:

```mermaid
flowchart LR
  A["▶ 이지 컴팩트<br/>(이득일 때만 버튼)"] --> B{"세션: 컴팩트하면<br/>잃을 정보가 있나?"}
  B -- 예 --> H["멈춤 — 아무것도 안 바뀜"]
  B -- 아니오 --> C["결정 · 진행 · 할 일<br/>저장"]
  C --> D["이어서 할 일<br/>3~5줄"]
  D --> E["/compact 가<br/>그 답을 남김"]
  E --> F["요약에서<br/>이어 가기"]
```

<img src="docs/img/summary.png" width="860" alt="컴팩트 뒤: 요약 카드에 이어서 할 일, 컨텍스트는 약 82k">

**컴팩트 뒤 요약에 이어서 할 일이 남고, 그 뒤 요청은 모두 싸집니다.** **기본 컴팩트** 는 저장 단계를 건너뛰고, **클리어** 는 요약 없이 대화를 비웁니다. 컴팩트하는 동안 현황의 컨텍스트 · 컴팩트 시점 막대가 천천히 숨 쉬고(*컴팩트 중…*), 끝나면 옛 크기에서 새 크기로 줄어듭니다.

### 5. 이지 컴팩트 패널

<img src="docs/img/simple.png" width="900" alt="간단 화면: 한 줄 바와 간단 이지 컴팩트 패널(이 세션 · 질문별 비용)">

바의 **게이지** 를 누르면 열립니다(터미널은 **[패널 ▸]**). 첫 탭 **현황** — **간단**(간단 화면의 처음 보기): **이 세션** — 누적 · 질문 수 · 메인 / 🤖 / ⚙ 와 *지금* 결정 한 줄(상태 · 숫자 하나 · 할 일), 컴팩트 구간 드롭다운 — 과 질문별 비용. **자세히**(자세히 화면의 처음 보기): 다른 모델로 했다면 · 컨텍스트 막대 · 컴팩트 시점(추천 · 비추천 · 크기별 비용 표) · 컨텍스트 흐름 · 컴팩트마다 아낀 값까지. 자세히 패널 맨 위엔 **모든 세션** 줄(이 PC 모든 세션의 오늘 · 이번 달)이 옵션과 상관없이 있고, 간단 패널엔 설정에서 켠 것만 보입니다. 탭 줄 오른쪽 **보기 [간단][자세히]** 로 바꾸면 그 보기를 기억합니다(설정의 화면 종류를 바꾸면 그 화면의 보기로). 열 때 질문별 비용은 접혀 있습니다. 기본은 떠 있는 데스크톱 세션끼리 같이 열고 닫고, 새 세션에서 저절로 열리지는 않습니다 — 설정 **패널** 탭에서 바꿉니다. 자세히 보기의 **크기별 비용** 표는 지금 컨텍스트가 든 줄을 옅은 파랑 바탕으로 보입니다(고른 구간은 테두리).

### 6. 터미널에서도

<img src="docs/img/terminal.png" width="900" alt="Claude Code 터미널의 같은 바와 이지 컴팩트 패널">

**CLI 에서도 같은 바와 패널.** 바의 버튼은 ctrl+x tab 으로 바에 들어가 누릅니다(전체 화면 모드면 클릭). 접은 바는 바 자리에 **[⇱ 이지 컴팩트]** 한 줄로 남아, 같은 키로 가서 Enter 하면 다시 펴집니다.

## 숨기기 · 접기 · 다시 켜기

창 버튼은 바의 오른쪽 위에 있습니다. 고른 것은 모든 세션에 적용되고, 앱을 껐다 켜도 남습니다.

| 버튼 | 하는 일 | 다시 돌아오는 법 |
|---|---|---|
| **—** / **□** | 한 줄 / 전체 | 다시 누르기 |
| **✕** 접기 | 모든 세션에서 바를 입력창 아래로 접습니다 | 컴팩트할 때(주황 · 캐시 만료) 저절로 — 또는 입력창 아래 **🟦 이지 컴팩트** 를 누르기(네모 색 = 지금 크기 단계 🟦 여유 · 🟧 컴팩트할 때 · 🟥 늦어짐). 터미널은 바 자리의 **[⇱ 이지 컴팩트]**(ctrl+x tab → Enter) |
| **게이지**(**컴팩트** 앞 동그라미) | 이지 컴팩트 패널 열기 · 닫기(터미널은 **[패널 ▸]**) | 다시 누르기 |

접힌 바가 저절로 펴질지는 설정 **바** 탭의 **컴팩트할 때 바 펴기**(기본 켬)가 정합니다. 끄면 누를 때까지 접힌 채이고 접힌 바 버튼이 회색(*닫힘*)이 됩니다 — 지울지 정하기 전에 잠시 쉬는 용도. 저절로 펴진 바를 다시 ✕ 로 접으면 더 급해질 때(빨강 · 캐시 만료)까지 기다립니다.

<img src="docs/img/fold.png" width="900" alt="바를 접은 뒤: 컴팩트할 때 저절로 펴진다는 알림, 입력창 아래 이지 컴팩트 버튼">

**슬래시 명령은 없습니다**(0.9.0 부터) — 바의 버튼과 패널의 **⚙ 설정** 탭에서 다 합니다. 설정은 맨 위 **화면 종류**(간단 · 자세히 · 커스텀) 아래 탭으로 나뉩니다: **바**(바 전체 — 바 크기 · 게이지 모양 · 바 접어 두기 · 컴팩트할 때 바 펴기 · 입력창 아래 한 줄 / 한도 줄 / 비용 줄 — 칸 · 모든 세션 · 세션 금액 색 · 비용 표시 순서 · 컨텍스트 숫자(크기 · % · 둘 다) / 질문 줄 — 카드마다 그 줄 미리보기), **답변 칩**(답변 칩 자세히 · 질문 강조), **패널**(새 세션에서 패널 열기 · 같이 여닫기), **컴팩트**(컴팩트 문구 · 캐시), **일반**(움직임(데스크톱) · 문제 제보 · 언어). 화면 종류가 정하는 칸은 커스텀에서 바꾸고 프리셋에선 흐리게 보입니다. 줄마다 풀이는 이름 옆 **?** 에 마우스를 올리면 보이고 누르면 펼친 채로 남습니다(터미널은 [ ? ] 를 눌러 펼침). 터미널에선 값 목록이 드롭다운 대신 옆으로 늘어선 버튼입니다. 컴팩트 시점은 현황 탭에서 고릅니다. 패널 오른쪽 위 버튼은 지금 버전을 보이고(폴더로 불러온 판은 *개발본*), 누르면 버전마다 바뀐 것 · **업데이트 확인** · **업데이트** · **문제 제보** 가 나옵니다. 캐시 유지 시간은 보이기만 합니다 — Claude Code 가 정하고(설정의 `promptCacheTtl` 또는 환경 변수), 이지 컴팩트는 설정을 고치지 않습니다.

**버튼은 토큰을 쓰지 않습니다** — 대화에 아무것도 남기지 않습니다.

**턴 끝 "다음 단계" 상자가 떠 있는 동안엔 바가 잠시 빠집니다.** Claude 가 턴 끝에 단추로 다음 할 일을 묻는 상자를 띄우면 앱이 그동안 플러그인 바를 뺍니다(앱 동작이라 플러그인이 못 막습니다 — 상자를 닫으면 돌아옴). 설정 **바** 탭 **입력창 아래 한 줄** 을 켜면 그동안에도 입력창 아래에 바의 요지가 남습니다 — 예: *🟦 이지 컴팩트 · 컨텍스트 140k · 컴팩트 구간 200k~250k · 세션 $8.40*.

## 바가 안 보이면

1. **판** — 2.1.295 이상이어야 합니다. 낮은 판은 바 자리에 업데이트 안내 한 줄이 뜨거나 아무것도 안 뜹니다 — [필요한 것](#필요한-것)의 방법으로 판을 보고 올리세요.
2. **설치됐나** — 터미널에서 `claude plugin list` → `easy-compact@easy-compact` 가 enabled 인지. 마켓 추가가 실패했으면 대개 `git` 이 없어서입니다.
3. **다시 켜기** — 데스크톱 앱은 창만 닫지 말고 완전히 끈 뒤 켜고, 새 세션을 엽니다. 터미널은 새 `claude` 세션.
4. **회사 관리 PC** — 관리자가 플러그인 · mod 를 막아 두었으면 뜨지 않습니다.
5. **턴 끝 "다음 단계" 상자** — 떠 있는 동안 앱이 바를 뺍니다(상자를 닫으면 돌아옴). 위 [입력창 아래 한 줄](#숨기기--접기--다시-켜기)을 켜면 그동안에도 요지가 남습니다.

그래도 안 되면 아래 [문제가 생기면](#문제가-생기면--제보)대로 알려 주세요.

## 문제가 생기면 — 제보

1. **진단 내용 보기** — 이지 컴팩트 패널(바의 게이지 · 터미널은 **[패널 ▸]**) → 탭 줄 오른쪽 버전 버튼(`v0.9.1 ▸`) → 서랍 **문제 제보** 의 **[진단 내용 보기]**(설정 **일반** 탭에도). 무엇이 들어 있는지와 처음 몇 줄이 보입니다 — 질문 글 · 답 끝 · 동작 이름 · 직접 쓴 문구는 처음부터 빠져 있습니다(스위치를 끄면 들어가고, 나갈 내 글이 노랗게 따로 보임). 본 그대로 **[복사]**(클립보드) 또는 **[파일로 저장]**(경로는 카드 · 알림에 — 대화엔 안 남습니다). **[이슈 쓰기 ↗]** 가 새 이슈 화면을 엽니다.
2. **담기는 것** — 설정 값 전부, 패널 상태(열린 탭 · 펼친 칸), 사용량 숫자 · 도는 질문 · 컴팩트 단계, 질문 기록(질문 글 · 질문별 비용 · 답 끝부분), 금액 대조 재료(엔진 집계 · 이지 컴팩트가 잰 합), 짝 없는 서로게이트 · 제어 문자 수(화면이 통째로 안 그려지는 원인 후보).
3. **어디에** — `~/.claude/plugins/data/easy-compact-easy-compact/debug-<세션 id>.json`(앤트로픽 디렉터리로 설치했으면 `plugins/data/easy-compact-synced/`). 같은 세션은 덮어씁니다.
4. **밖으로 안 나갑니다** — 이지 컴팩트는 파일을 보내지 않습니다. 제보할 때 직접 붙여 주세요. 질문 글과 금액이 들어 있으니 올리기 전에 한 번 보고, 감출 것은 지우세요.
5. **[이슈](https://github.com/JaeSeongHa5280/easy-compact/issues)에 적을 것** — 증상, 재현 순서, 화면(데스크톱 앱 / 터미널), 버전(버전 버튼 · `/status` 의 Claude Code 판), OS, 그리고 진단 파일.

## 알아 둘 것

- **금액은 API 정가 환산입니다.** 구독 요금제라면 청구액이 아니라 세션이 얼마나 무거운지로 읽으세요.
- **모든 것이 내 PC 안에서 돕니다.** easy-compact 는 로컬 세션 기록만 읽고 스스로 네트워크 요청을 하지 않습니다. 패널 버전 버튼 아래 **[업데이트 확인]** · **[업데이트]** 를 누를 때만 Claude Code(`claude plugin` 명령)가 GitHub 에서 마켓을 받아 옵니다.
- **운영체제:** Windows 11 에서 만들고 시험했습니다. OS 에 묶인 코드는 없지만 macOS · Linux 는 아직 실물로 시험하지 않았습니다 — 써 보고 알려 주시면 반영합니다.
- **데스크톱 앱:** 패널을 연 직후 패널 안 첫 클릭은 포커스만 옮깁니다. 한 번 더 누르세요.
- 4MB 가 넘는 기록은 Node.js(14.8 이상)로 읽습니다. `node` 가 없으면 아주 긴 세션의 앞 구간은 빼고 설치한 뒤부터 그립니다(그렇다고 알려 줌). 오늘 · 이번 달 사용량도 Node.js 로 셉니다 — 없으면 바엔 그 칸이 뜨지 않고 패널 **모든 세션** 줄엔 *못 잼* 과 까닭이 나옵니다. 다른 세션 기록(토큰 수만)은 그 옵션을 켰거나 패널 현황 탭을 자세히로 볼 때만 읽습니다. 오늘 · 이번 달의 날짜 경계는 UTC(한국 시간 오전 9시)입니다. 세션 기록에 없는 요청 — 컴팩트 요약 · Claude Code 가 스스로 보내는 요청 — 도 이지 컴팩트가 잰 값으로 더합니다(앞날은 질문별 비용 기록에서). 다른 컴퓨터 · 웹에서 쓴 몫은 셀 수 없습니다.
